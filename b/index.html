01 · 背景与问题01 · Background & problem

电容式土壤湿度传感器为什么会漂移Why capacitive soil-moisture sensors drift

低成本电容式土壤湿度传感器的读数会随温度变化、土壤盐分波动和电极老化而系统性偏移。多数低价模块不带温度补偿电路，长期部署后读数会逐渐偏离真实含水量，且偏移方向和幅度因批次而异，难以用固定偏移量一次性修正。Readings from low-cost capacitive soil-moisture sensors drift systematically with temperature swings, soil-salinity changes, and electrode aging. Most inexpensive modules have no temperature-compensation circuit; after long deployment, readings gradually diverge from true moisture content, and the direction and magnitude of drift vary by batch, so a single fixed offset cannot correct it.

02 · PetrichorSync 协议要点02 · PetrichorSync protocol overview

配对参考传感器与微校准脉冲Paired reference sensor and micro-calibration pulses

配对参考传感器Paired reference sensor

每组部署传感器配一支密封参考探头，读数不受土壤盐分影响，用于估计漂移基线。Each deployed group pairs with a sealed reference probe unaffected by soil salinity, used to estimate the drift baseline.

周期性微校准脉冲Periodic micro-calibration pulse

每 6 小时施加一次低幅度激励脉冲，比较响应曲线与出厂基线的偏差，估算当前漂移量。A low-amplitude excitation pulse is applied every 6 hours; comparing the response curve against the factory baseline estimates the current drift.

分段线性补偿Piecewise-linear compensation

按温度区间分段拟合补偿曲线，避免单一线性模型在极端温度下失效。Compensation curves are fitted per temperature band, avoiding failure of a single linear model at extreme temperatures.

置信度标记Confidence flagging

当校准脉冲响应异常或参考探头读数不稳定时，该次补偿标记为低置信度并回退到保守估计。When the pulse response is abnormal or the reference probe is unstable, that compensation is flagged low-confidence and falls back to a conservative estimate.

03 · 校准流程03 · Calibration procedure

从部署到持续补偿From deployment to ongoing compensation

  1. 部署时记录出厂响应曲线与参考探头基线；record the factory response curve and reference-probe baseline at deployment;
  2. 每 6 小时触发一次微校准脉冲并采集响应；trigger a micro-calibration pulse and collect the response every 6 hours;
  3. 按温度区间比对响应曲线，计算漂移估计值；compare response curves per temperature band to compute the drift estimate;
  4. 若参考探头或脉冲响应异常，标记本次估计为低置信度；flag the estimate low-confidence if the reference probe or pulse response is abnormal;
  5. 将补偿值写入本地读数流水线，累计记录用于后续复检。write the compensation value into the local reading pipeline and log it for later review.

04 · 初步测试结果04 · Preliminary results

7 天对比测试7-day comparison trial

在 240 支传感器、为期 7 天的田间对比测试中，未校准组的漂移误差为 ±4.2%，应用 PetrichorSync 微校准后降至 ±0.6%。测试覆盖 3 种土壤类型和昼夜温差约 18°C 的环境，结果为初步观测，尚未经过独立复现。In a 7-day field trial with 240 sensors, the uncalibrated group showed ±4.2% drift error; applying PetrichorSync micro-calibration reduced it to ±0.6%. The trial covered 3 soil types and a diurnal temperature swing of about 18°C. These are preliminary observations, not yet independently reproduced.

05 · 常见问题05 · FAQ

FAQFAQ

PetrichorSync 需要额外硬件吗？Does PetrichorSync need extra hardware?

需要一支密封参考探头和可编程激励脉冲的驱动电路，多数低成本模块可通过固件升级支持。It needs a sealed reference probe and a driver circuit capable of a programmable excitation pulse; most low-cost modules can support this via a firmware update.

校准间隔可以调整吗？Can the calibration interval be changed?

可以，6 小时是本次测试使用的默认值，更短间隔会提高精度但增加功耗。Yes — 6 hours was the default used in this trial; a shorter interval improves accuracy but increases power draw.

这个结果适用于所有传感器型号吗？Does this result generalize to all sensor models?

目前仅在测试所用的批次上验证，跨型号和跨厂商的效果尚未测试。It has only been verified on the batch used in this trial; cross-model and cross-vendor performance has not been tested.
